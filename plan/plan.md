# 自動洗閃炫方塊
此專案使用 Python 讀取當前電腦畫面並控制滑鼠，以達到自動使用楓之谷"結合方塊"的功能。

- 滑鼠控制：pyautogui
- 畫面文字辨識：PaddleOCR(繁體中文模型 `chinese_cht`)
- 視窗尋找/擷取：pywin32 + mss

# 結合方塊使用說明
- 使用後會遊戲畫面上會出現一個視窗，該視窗顯示裝備目前的3個潛能
- 其中一個潛能的底色會與其他2個潛能不同，代表該潛能已被選取，按下"重新設定"時會刷新該潛能
- 若選擇的潛能不是想要的潛能，點擊"重新選擇"後遊戲會重新選擇一個潛能 (可能相同)

# 程式執行設定
使用者在執行前可以在 `config.json` 設定以下內容:
- `target_potentials`：使用結合方塊後所需要的目標潛能
	- 是「多組允許的目標組合」所組成的 list，每一組固定為3個字串槽位，依序代表3個潛能槽位
	- 允許空字串，空字串代表該潛能不是想刷新的潛能，一組目標組合必須包含2個空字串
	- 字串可以只寫潛能名稱(例如"魔法攻擊力")代表不限數值，也可以連數值一起寫
	  (例如"魔法攻擊力 +12%")，此時數值也必須完全相同才算符合，用來區分同名
	  但不同數值的重複選項(例如"無視怪物防禦率"同時出現 +30% 和 +40% 兩種)
	- **list 中排越前面的組合優先權越高**：每一輪先讀取目前被選取的是哪一個位置
	  (上/中/下)，依優先權由高到低尋找第一個「目標位置與目前被選取位置相同」的
	  組合，以它來指導這輪的操作(見下方「流程規劃」步驟4)；若沒有任何組合的目標
	  位置等於目前被選取的位置，代表這格不是想要的位置，改點"重新選擇"換一格。
	  最終畫面上3個潛能只要**在對應位置**滿足**其中任一組合**就算達成目標
- `max_cubes`：使用者可以設定最多使用多少方塊
	- 設定值為0時代表不限制
- `regions`：所有滑鼠點擊/畫面讀取用的座標，可用 `python tools/locate.py`
	依提示逐項互動校正，不需要改程式碼
- `dry_run`：設為 `true` 時只讀取畫面、印出判斷結果，不會真的點擊滑鼠

# 流程規劃
1. 使用者須提前開啟使用結合方塊的介面並點選結合方塊
(以下皆為程式自動控制)
2. 判斷當前畫面中使用者選擇的是否是"結合方塊" (如圖step1紅框)
	- 完全讀不到文字(代表面板可能根本沒開/畫面座標對不上)才視為致命錯誤並中止程式
	- 讀到文字但與"結合方塊"相似度偏低，只印出警告訊息、不中止流程，交由使用者自行確認畫面狀態是否正確
3. 控制滑鼠按下"重新設定"按鈕 (如圖step2紅框)，遊戲畫面中出現提示框，程式操控滑鼠按下"確定"按鈕 (如圖step3紅框)，按下後會另外跳出一個「結合方塊」小視窗(如圖step4紅框)
	- 這個步驟只在程式一開始執行一次，用來叫出step4開始的小視窗；之後每一輪重骰都直接操作小視窗裡的"重新選擇"/"重新設定"(見步驟4)，不需要再次點擊這裡的"重新設定"
4. 遊戲畫面出現3個潛能(如圖step4紅框)，且其中一個的文字底色會與其他的不同，代表被選取(如圖step5紅框，底色顏色可能為紫/橘/綠，也可能選擇不同位置的潛能)，程式讀取這3個潛能的內容(潛能名稱+數值，依上/中/下固定位置)，以及目前被選取的是哪一個位置，並根據使用者設定的內容進行以下判斷，直到達成目標、或已達到設定的方塊使用上限為止：
	1. 先確認目前這3個潛能是否已經**在對應位置**滿足 `target_potentials` 中任一組合，若是則點擊"離開"鈕，結束流程
	2. 否則，從 `target_potentials` 依優先權由高到低尋找「目標位置＝目前被選取的位置」的第一個組合
		1. 若有找到，代表目前被選取的位置正是想要的目標，點選畫面上的"重新設定"鈕，重新設定該格潛能 (如圖step7紅框)：按下後會出現一個確認視窗，需按下"確認"鈕 (如圖step7_1紅框)，按下確認鈕後會刷新該格潛能(消耗1個結合方塊)
		2. 若沒有找到，代表目前被選取的位置不是想要的目標，點選畫面上的"重新選擇"鈕 (如圖step6紅框)：按下後會出現一個確認視窗，需按下"確認"鈕 (如圖step6_1紅框)，按下確認鈕後會重新選擇一個位置(可能相同，消耗1個結合方塊，但不會改變3個潛能的內容)
	3. 重複步驟1到2直到達成目標、或已達到設定的方塊使用上限為止(達到上限時也點擊"離開"鈕結束流程)

# 其他設計
- 緊急停止：執行期間把滑鼠移到螢幕任一角落即會觸發 pyautogui 的 fail-safe
  中止；也可以直接按 Ctrl+C；或按下 `stop_hotkey` 設定的全域熱鍵(預設
  `ctrl+f2`)，不用切換視窗、遊戲畫面保持在前景也能觸發，會在目前這一輪跑完
  後收尾(自動點擊"離開")，不是立即中斷
- GUI 全域熱鍵：`start_hotkey`(預設 `ctrl+f1`)/`stop_hotkey` 對應開始/停止；
  座標校正對話框另有 `calibrate_confirm_hotkey`/`calibrate_skip_hotkey`/
  `calibrate_finish_hotkey`(預設 `ctrl+f3`/`ctrl+f4`/`ctrl+f5`)對應
  記錄/跳過/結束——校正時滑鼠要停在遊戲畫面定點，用熱鍵觸發才不會因為點擊
  對話框按鈕而讓滑鼠移位，記錄到錯誤的座標
- 所有座標皆以「參考解析度」為基準記錄、執行時等比例換算，對遊戲視窗大小的
  些微差異有一定容錯度
